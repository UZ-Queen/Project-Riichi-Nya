# Feature Landscape

**Domain:** 기존 Unity 리치마작 프로젝트의 단계형 1인 조패·더미 4인 반장전
**Researched:** 2026-08-28
**Overall confidence:** MEDIUM — 프로젝트 범위와 현행 코드는 HIGH, 규칙 주장은 최신 WRC 색인과 WRC 2022·EMA 2025 공식 규칙을 교차 확인했으나 검색 제공자 분류는 MEDIUM이다.

## Fixed Basic Rule Contract

이 표는 보편 규칙이라고 가장하지 않고, 9일 안에 하나의 일관된 반장전을 완성하기 위한 **프로젝트 고정 규칙**을 정의한다. WRC와 다른 항목은 프로젝트 오버라이드로 명시한다.

| Rule | Fixed behavior | Scope note |
|------|----------------|------------|
| 패 구성 | 136장, 각 TileID 4장. 각 수패의 일반 5 한 장을 적5로 교체해 적5는 만·통·삭 각 1장 | 프로젝트의 기존 적도라 자산과 확인된 139장 버그 수정 방향을 따른다. WRC 대회 규칙의 적도라 유무와는 별도인 프로젝트 오버라이드다. |
| 시작 점수·좌석 | 네 좌석 각 25,000점, 인간은 최초 동가로 시작하고 이후 국 진행에 따라 좌석풍이 회전 | 좌석 추첨·설정 UI는 만들지 않는다. 고정 시작은 재현 가능한 시연에 유리하다. |
| 대국 길이 | 동장과 남장만 진행. 남4국도 친 연장 조건을 적용하고, 친이 넘어가면 종료. 서입과 오라스 종료 선택은 없음 | 프로젝트에서 합의된 반장·남4국 종료 범위다. |
| 친 연장 | 친 화료 또는 유국 시 친 텐파이면 같은 국을 반복. 비친 화료 또는 친 노텐 유국이면 좌석과 국을 진행 | WRC/EMA 기본 진행과 일치한다. 더미 친의 실제 손패도 텐파이 판정에 포함한다. |
| 본장 | 친 화료 또는 모든 유국마다 +1. 비친 화료 시 0으로 초기화. 쯔모는 각 지불자 +100점/본장, 론은 방총자 +300점/본장 | 단순 표준 정산으로 고정한다. |
| 유국 정산 | 패산 소진만 통상 유국으로 처리. 텐파이/노텐 간 총 3,000점을 표준 배분. 0명 또는 4명 텐파이면 이동 없음 | 사풍연타·구종구패·사개리치·사깡산료 등 도중유국은 구현하지 않는다. |
| 리치 | 멘젠 텐파이, 유효한 리치 타패, 1,000점 이상 보유, 라이브 월에 다음 자기 쯔모가 남을 때만 선언. 1,000점을 공탁하고 손패를 고정 | 1,000점 미만 리치를 허용하는 WRC 규칙 대신 일반 디지털 플랫폼형 제한을 프로젝트 고정 규칙으로 선택한다. 파산 종료는 없다. |
| 리치봉 | 다음 인간 화료자가 모두 회수. 유국이면 이월. 반장 종료 시 미회수 봉은 테이블에 남아 어느 좌석에도 지급하지 않음 | 인간만 화료하므로 수령자 분기와 다중 론 분배가 없다. 종료 화면에서 미회수 봉을 별도로 표시한다. |
| 후리텐 | 자기 하천의 어느 대기패라도 포함되면 모든 론 불가. 화료 가능한 타패를 넘기면 다음 자기 쯔모/후로까지 일시 후리텐, 리치 후 넘기면 국 종료까지 지속 | 쯔모 화료는 허용한다. 더미 타패 뒤 반응 창 없이는 정확히 구현할 수 없다. |
| 화료자 | 인간만 쯔모·론 가능. 더미는 완성패라도 화료하지 않음 | 의도적인 시뮬레이션 제약이며 완전한 4인 마작과 다르다. |
| 후로자 | 3단계에서도 인간만 치·퐁·대명깡·암깡·가깡 가능 | 더미의 후로와 모든 판단은 AI 단계로 연기한다. |
| 열린 탕야오 | 허용 | 열린 손의 최소한의 일반적 역 선택지를 보장한다. 도라만으로는 화료할 수 없다. |
| 깡도라 | 모든 성립한 깡에서 영상패를 뽑고, 타패 전에 새 깡도라 표시패를 공개 | 한 가지 타이밍만 구현한다. 가깡이 론으로 저지되면 깡은 성립하지 않고 깡도라도 공개하지 않는다. 현재 더미는 론하지 않으므로 이 저지는 도메인 규칙으로만 남고 플레이에서는 발생하지 않는다. |
| 파산·순위 보너스 | 음수 점수여도 계속하며 토비 종료 없음. 오카·우마·랭크 보너스 없음 | 9일 포트폴리오에서 대국 흐름과 정확한 국 정산만 다룬다. |

## Table Stakes

### Stage 1 — Timed Solo Preservation and Riichi

기존 1인 모드는 반장전의 축약판이 아니라 별도의 아케이드 조패 경험이다. 공통 패·화료·역·부·점수 엔진만 공유하고 타이머·거리·부스트·고득점 흐름은 유지한다.

| Feature | Why Expected | Complexity | Notes |
|---------|--------------|------------|-------|
| 180초 조패 루프 보존 | 현재 제품의 고유 플레이 경험이며 새 반장전 때문에 삭제되면 안 된다 | Med | 시작 → 13장 배패 → 쯔모 → 타패 → 화료/유국 후 새 손 → 시간 종료를 유지한다. 반장 좌석·노텐벌부·네 명 점수 이동을 이 모드에 섞지 않는다. |
| 기존 점수·부스트·거리 연결 보존 | 화료 보상이 이동 속도와 최종 거리로 이어지는 것이 모드의 핵심 피드백이다 | Med | 화료 기본점만 아케이드 보상으로 전달한다. 자기 리치봉 회수는 새 보상으로 중복 변환하지 않는다. |
| 정상 종료·포기·재시작 | 한 번 플레이한 뒤 두 번째 실행이 망가지면 포트폴리오 빌드로 사용할 수 없다 | Med | 타이머 0, Escape 포기, 결과·고득점 저장, 같은 씬에서 재시작을 검증한다. 중복 이벤트, 패널 토글, 음수 타이머를 수정한다. |
| 규칙 엔진의 치명 오류 수정 | 리치 가능 여부와 화료 점수가 잘못되면 새 기능의 기반도 잘못된다 | High | 136장/4장 불변식, 편향 없는 셔플, 모든 화료 분해 탐색과 최고점 선택, 역만 배수, 쯔모 지불 합계를 먼저 고친다. |
| 리치 가능 타패 표시 | 단순히 “텐파이 가능” 버튼만 켜는 것으로는 사용자가 어떤 패를 버려야 하는지 알 수 없다 | Med | 14장 상태에서 버리면 텐파이가 되는 인덱스만 선택 가능하게 표시한다. 리치 입력 후 유효한 타패를 확정해야 선언이 성립한다. |
| 리치 상태와 1,000점 공탁 | 리치는 버튼이 아니라 지속 상태와 점수 이동을 갖는 선언이다 | Med | 선언 완료 시 1,000점을 차감하고 리치 타패를 표시한다. 이후 일반 타패 선택을 막고 쯔모기리·화료·조건부 암깡만 허용한다. |
| 리치 역·일발·우라도라 | 리치의 사용 가치가 실제 점수 결과에 반영되어야 한다 | High | 선언 시점·중단 이벤트·우라도라 표시를 `MahjongHandInfo`까지 전달한다. 일발은 다음 타패 전 화료이고 어떤 후로나 깡으로도 끊긴다. |
| 솔로 유국·시간 종료와 리치봉 분리 | 반장용 공탁 상태가 아케이드 진행을 멈추거나 부스트를 부풀리면 안 된다 | Low | 패산 소진이면 다음 솔로 손으로 진행하고 공탁은 다음 솔로 화료까지 이월한다. 시간 종료 시 남은 공탁은 최종 거리 보상에 더하지 않는다. |
| Windows Player 빌드와 최소 회귀 테스트 | Editor에서만 동작하는 기능은 제출물로 사용할 수 없다 | Med | 런타임 `UnityEditor` 참조를 제거하고, 순수 규칙 EditMode 테스트와 “시작→종료→재시작” PlayMode 스모크를 통과한다. |

### Stage 2 — Fixed Hanchan with Three Tsumogiri Dummies

| Feature | Why Expected | Complexity | Notes |
|---------|--------------|------------|-------|
| 명시적 4좌석 테이블 상태 | 네 점수, 좌석풍, 손패, 하천, 턴 주인, 패산과 왕패 없이는 론·친 연장·정산을 일관되게 처리할 수 없다 | High | 인간 1명과 더미 3명을 같은 좌석 모델로 보유하되, 행동 정책은 분리한다. |
| 더미의 정확한 쯔모기리 | “AI 없음”을 검증 가능한 행동 계약으로 만든다 | Low | 더미는 자기 차례에 라이브 월의 다음 패를 뽑고 **그 패 자체를 그대로 버린다**. 손패 13장은 바꾸지 않으며 전략 계산을 호출하지 않는다. |
| 더미와 AI의 UI·문서 구분 | 관전자에게 무작위/전략 AI로 오해시키면 포트폴리오 설명이 부정확해진다 | Low | 좌석 또는 모드 설명에 `Tsumogiri Dummy`라고 표기한다. “CPU/AI 난이도”, 생각 시간, 전략 로그는 만들지 않는다. |
| 더미의 금지 행동 | 더미 행동이 하나라도 늘면 AI·상대 규칙 범위가 급격히 커진다 | Low | 더미는 리치, 쯔모, 론, 치, 퐁, 모든 깡을 선언하지 않는다. 완성패여도 계속 쯔모기리한다. |
| 더미 손패의 규칙상 존재 | 더미가 단순 애니메이션이면 패 수량·유국·친 텐파이 정산이 깨진다 | Med | 정상 배패와 13장 손패를 가지며 적법한 패 수량을 점유한다. 유국 시 실제 텐파이/노텐 판정과 3,000점 정산에는 참여한다. |
| 인간 턴의 쯔모·타패 | 반장전의 기본 상호작용이다 | Med | 자기 쯔모 후 쯔모 화료 또는 14장 중 타패. 리치 상태이면 합법 암깡 외에는 쯔모기리만 가능하다. |
| 더미 타패 후 론 반응 창 | 자동으로 다음 턴을 시작하면 인간의 론 기회가 사라진다 | High | 각 더미 타패마다 다음 쯔모 전에 `Ron`/`Pass` 판정을 한 번 연다. 유효 화료 형태, 최소 1역, 후리텐을 모두 통과할 때만 Ron을 제시한다. |
| 후리텐과 론 패스 추적 | 론이 있는 리치마작에서 생략할 수 없는 합법성 경계다 | High | 자기 하천 후리텐, 일시 후리텐, 리치 후 영구적 패스 후리텐을 별도 상태로 추적한다. 다음 자기 쯔모/후로 시점의 해제를 테스트한다. |
| 인간만 화료하는 점수 이동 | 더미가 이기지 않아도 네 좌석 점수 보존과 친/자 정산은 보여야 한다 | High | 인간 론은 방총 더미가 전액+본장 지불, 인간 쯔모는 세 더미가 친/자 지분+본장 지불한다. 리치봉 회수와 반올림된 지불 합계를 같은 정산 결과에서 표시한다. |
| 리치의 반장 통합 | 1단계 기능이 실제 4좌석 타패·론·우라도라와 연결되어야 공유 엔진 가치가 드러난다 | High | 1,000점 공탁, 리치 하천 표시, 손패 고정, 일발, 우라도라, 리치 후 론 패스 후리텐을 테이블 상태에 적용한다. |
| 통상 유국과 3,000점 노텐벌부 | 화료가 없는 국이 많은 더미 환경에서는 진행 필수 기능이다 | High | 모든 좌석 텐파이를 평가하고 표준 0/1000/1500/3000 배분을 적용한다. 리치봉은 이월하고 본장은 증가한다. |
| 동1국~남4국 진행 | “한 국 시연”이 아니라 고정 반장전이라는 약속을 충족한다 | High | 친 승리/텐파이 유국 연장, 좌석풍·장풍 변경, 본장·리치봉, 남4국 친 연장 후 종료까지 처리한다. |
| 반장 HUD와 결과 | 사용자가 턴·좌석·점수 이동을 확인할 수 있어야 한다 | Med | 장풍/국/본장/리치봉, 네 좌석 점수·좌석풍, 각 하천, 남은 라이브 월, 도라 표시, 화료자·방총자·지불 내역을 표시한다. 전면 아트 개편은 하지 않는다. |

### Stage 3 — Human Calls, Open Hands, and Kan Flow

이 단계는 Stage 2의 4좌석 턴·론 반응 창·정산·유국이 테스트로 고정된 뒤에만 시작한다.

| Feature | Why Expected | Complexity | Notes |
|---------|--------------|------------|-------|
| 합법 행동 제시와 명시적 Pass | 후로는 타패마다 가능한 조합과 선택 결과가 달라진다 | High | 더미 타패 후 Ron을 최우선으로 평가하고, 인간에게 가능한 Chi/Pon/Daiminkan 조합과 Pass만 표시한다. 다음 쯔모는 선택이 끝난 뒤 진행한다. |
| 치 | 순서상 바로 왼쪽 좌석의 직전 타패로만 슌쯔를 만든다 | Med | 복수 조합이면 사용할 두 패를 선택한다. 멘츠 공개 후 쯔모 없이 인간이 한 장 버리고, 호출자 다음 좌석부터 진행한다. |
| 퐁 | 어느 더미의 직전 타패든 같은 패 2장으로 커쯔를 만든다 | Med | 공개 멘츠를 기록하고 쯔모 없이 타패한다. 같은 타패에 치와 퐁이 경쟁하면 퐁이 우선이지만 현재 호출자는 인간 하나뿐이다. |
| 대명깡 | 어느 더미의 직전 타패든 같은 패 3장으로 공개 깡을 만든다 | High | 깡 성립 → 라이브 월 끝 1장을 왕패로 이동 → 영상패 쯔모 → 깡도라 공개 → 쯔모/타패 순서다. 정상 쯔모를 추가로 하지 않는다. |
| 암깡 | 자기 턴에 같은 은폐패 4장으로 폐쇄 깡을 만든다 | High | 암깡만으로 손은 멘젠을 유지한다. 리치 후에는 방금 뽑은 패를 포함하고 원래 패 구조와 대기가 바뀌지 않을 때만 허용한다. |
| 가깡 | 자기 턴의 쯔모패 또는 손패로 기존 공개 퐁에 네 번째 패를 추가한다 | High | 가깡 선언 시 표준적으로 창깡 론 창이 먼저지만, 더미는 론하지 않으므로 현재 플레이에서는 즉시 성립한다. 미래 AI를 위해 “성립 전” 상태만 분리하고 창깡 UI는 만들지 않는다. |
| 깡 공통 불변식 | 패산 수량과 다음 턴이 틀리면 국 전체가 오염된다 | High | 왕패는 항상 14장, 영상패는 최대 4장, 깡마다 라이브 월 마지막 1장을 왕패로 보충, 4깡 이후 5번째 깡 금지, 마지막 라이브 월 쯔모 뒤 깡 금지로 고정한다. 사깡산료는 없다. |
| 영상개화 | 깡의 직접 보상이 점수에 반영되어야 한다 | Med | 영상패로 인간이 화료하면 쯔모로 정산하고 1판 영상개화 역과 쯔모 2부를 적용한다. 해저와 중복하지 않는다. |
| 깡도라·깡우라도라 | 깡과 리치가 점수 계산에 함께 반영되어야 한다 | High | 성립한 각 깡의 표시패를 즉시 활성화한다. 인간이 리치 화료하면 활성 도라·깡도라 각각의 아래 우라도라/깡우라도라를 공개한다. 도라는 역이 아니다. |
| 열린 손 화료 판정 | 13장 은폐손 전제의 기존 솔버로는 후로 후 남은 손패를 잘못 판정한다 | High | 고정된 공개 멘츠를 입력으로 받고 남은 은폐패만 분해해 전체 4멘츠 1머리를 구성한다. 가능한 모든 분해 중 실제 지불액이 최대인 결과를 고른다. |
| 열린 손 역 제한과 쿠이사가리 | 멘젠 전용 역·감소 역을 그대로 계산하면 점수가 과대 산정된다 | High | 리치·일발·멘젠쯔모·핑후·이페코 등 멘젠 전용 역은 제거한다. 탕야오·역패 등 열린 역은 유지한다. 일기통관/삼색동순/찬타 2→1, 혼일색 3→2, 준찬 3→2, 청일색 6→5를 적용한다. |
| 열린 손 부 계산 | 퐁·깡과 론/쯔모에 따라 부가 크게 달라진다 | High | 공개 중장패 커쯔 2부/요구패 4부, 공개 중장패 깡 8부/요구패 16부, 암커쯔·암깡은 각각 두 배, 쯔모 2부, 멘젠 론 10부, 대기·역패 머리 부를 계산한다. 열린 핑후형은 30부가 되도록 2부를 부여한다. |
| 쿠이카에 금지 | 호출 직후 동일패나 치의 반대편 패를 버리는 규칙 변형을 하나로 고정해야 한다 | Med | WRC식으로 동일패 즉시 타패와 치의 반대편 교환 타패를 금지한다. UI에서 불법 타패를 선택 불가로 만든다. |
| 후로와 리치·일발 상호작용 | 상태가 서로 배타적이거나 중단 조건을 만든다 | Med | 치/퐁/대명깡/가깡은 손을 열어 이후 리치를 금지한다. 암깡은 멘젠을 유지한다. 어떤 후로나 깡도 진행 중 일발을 끊는다. 리치 후 일반 후로와 가깡은 불가다. |

## Differentiators

기능 수보다 “기존 오작동을 규칙 계약과 테스트로 고쳤다”는 증거가 NEXON 포트폴리오에서 더 가치 있다.

| Feature | Value Proposition | Complexity | Notes |
|---------|-------------------|------------|-------|
| 두 모드가 공유하는 순수 규칙 결과 | 같은 패가 솔로와 반장에서 같은 화료 형태·역·부·기본점을 내고, 진행·보상만 달라지는 구조를 시연한다 | Med | 별도 규칙 복제 없이 한 테스트 표를 두 모드 어댑터에 적용한다. |
| 합법 행동 이유 표시 | “리치 불가: 열린 손”, “론 불가: 후리텐”, “깡 불가: 대기 변경”처럼 결정 근거를 보여 주면 디버깅·설계 역량이 드러난다 | Med | 전체 튜토리얼 대신 버튼 비활성 사유 한 줄이면 충분하다. |
| 화료 정산 상세 | 역·판·부뿐 아니라 쯔모 지불자별 금액, 론 방총자, 본장, 리치봉, 도라 종류를 분리 표시한다 | Med | 현재 론 총액을 쯔모에도 재사용하는 오류의 개선 전후 증거가 된다. |
| 재현 가능한 시연 시드 | 동일 패산으로 리치·론·깡 사례를 반복 시연하고 테스트 실패를 재현할 수 있다 | Low | 사용자 설정 메뉴는 만들지 않고 개발/포트폴리오용 시드 기록과 테스트 fixture만 둔다. |
| `Tsumogiri Dummy` 명시와 빠른 턴 표현 | 과장된 AI 주장 없이 4좌석 상태 머신 자체를 정확히 보여 준다 | Low | 더미는 전략 점수나 랜덤 대기 시간을 쓰지 않는다. 쯔모패가 바로 하천으로 이동하는 짧은 연출이면 충분하다. |

### Critical Rule Interactions

| Interaction | Required behavior | Failure if omitted |
|-------------|-------------------|--------------------|
| 리치 × 론 패스 | 리치 뒤 화료 가능한 타패를 넘기면 국 종료까지 론 불가, 쯔모는 가능 | 같은 리치 손이 임의로 다시 론해 방어 규칙이 무너진다. |
| 리치 × 암깡 | 방금 쯔모한 패로 만들고 원래 구조·대기가 동일할 때만 허용 | 리치 후 손패 변경으로 선언 당시 텐파이 계약이 깨진다. |
| 리치 × 후로 | 리치 뒤 치·퐁·대명깡·가깡 불가. 앞서 후로한 열린 손은 리치 불가 | 멘젠 전용 역과 우라도라가 열린 손에 잘못 적용된다. |
| 후로 × 화료 | 열린 손도 4멘츠 1머리와 최소 1역 필요. 도라만으로 화료 불가 | 열린 도라 손이 무역 화료하거나 멘젠 역을 받는다. |
| 론 × 커쯔 부 | 론패가 샤보 대기의 커쯔를 완성하면 그 커쯔는 공개 커쯔 부로 계산 | 산안커·부 계산이 과대 평가된다. |
| 대명깡 × 턴 | 호출 직후 정상 쯔모 없이 영상패를 뽑고, 화료하지 않으면 한 장 타패 | 15장 상태 또는 이중 쯔모가 발생한다. |
| 가깡 × 창깡 | 표준상 네 번째 패가 깡 성립 전에 론 대상. 현재는 더미가 론하지 않아 도달 불가 | 미래 상대 화료 추가 시 상태 재작성 위험이 생기므로 성립 경계는 남겨야 한다. |
| 깡 × 패산 | 영상패 1장 사용 때 라이브 월 1장을 왕패로 이동해 왕패 14장을 유지 | 유국 시점과 총 패 수가 어긋난다. |
| 깡 × 도라 | 성립한 깡만 표시패 추가. 가깡이 창깡으로 저지되면 추가하지 않음 | 존재하지 않는 깡도라가 점수에 포함된다. |
| 더미 × 텐파이 | 더미는 화료하지 않지만 유국의 텐파이/친 연장/노텐벌부에는 실제 손으로 참여 | 더미가 빈 좌석이 되어 반장 진행과 점수 보존이 왜곡된다. |

## MVP Recommendation

Prioritize:

1. **Stage 1 규칙 기반과 솔로 회귀 안정화** — 136장, 셔플, 완전 분해, 점수, 재시작, Player 빌드가 먼저다.
2. **Stage 1 리치의 완전한 한 사이클** — 가능 타패 선택, 공탁, 손패 고정, 리치 역·일발·우라도라까지 끝낸다.
3. **Stage 2 고정 반장전** — 4좌석 상태, 쯔모기리 더미, 인간 쯔모/론, 후리텐, 정산, 유국, 동남장 진행을 완료한다.
4. **제출 증거** — EditMode 표 기반 규칙 테스트, PlayMode 시작→종료→재시작, Windows 빌드, 개선 전후 3~5건을 남긴다.
5. **Stage 3는 남은 시간에만** — 치/퐁을 먼저 수직 완성하고, 세 깡과 열린 손 점수까지 하나의 검증된 묶음으로 완료할 수 있을 때 확장한다.

Defer:

- **Stage 3 전체 또는 일부:** Stage 2 테스트가 불안정하면 기능 수를 위해 합치지 않는다. 특히 깡은 왕패·턴·점수·도라가 모두 연결되므로 “버튼만 있는 깡”을 제출하지 않는다.
- **AI와 상대 화료:** 합법 행동·정산·후로 상태가 검증된 이후 별도 단계로 둔다.
- **규칙 변형:** Fixed Basic Rule Contract 외 모든 선택지는 설정으로 노출하지 않는다.
