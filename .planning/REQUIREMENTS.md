# Requirements: Project Riichi Nya

**Defined:** 2026-08-28
**Core Value:** 기존 마작 로직을 정확하고 테스트 가능하며 유지보수하기 쉬운 규칙 엔진으로 개선하고, 그 엔진이 서로 다른 1인·4인 플레이 흐름에 재사용되는 과정을 검증 가능한 전후 증거로 보여준다.

## v1 Requirements

### Executable Baseline

- [ ] **BASE-01**: 개발자는 기존 소스 기준 커밋 `b18320e`를 `portfolio-baseline` annotated tag로 재현할 수 있다.
- [ ] **BASE-02**: 개발자는 고정된 시드와 행동 기록으로 대표 솔로 패 진행을 반복 재현할 수 있다.
- [ ] **BASE-03**: Windows Player 빌드는 런타임 코드의 `UnityEditor` 참조 없이 컴파일되고 실행된다.
- [ ] **BASE-04**: 개발자는 Unity Test Framework에서 프로젝트 규칙 EditMode 테스트를 배치 실행하고 결과 파일을 얻을 수 있다.
- [ ] **BASE-05**: 플레이어는 같은 실행 세션에서 솔로 게임을 시작하고 종료 또는 포기한 뒤 다시 시작할 수 있다.

### Shared Rules Core

- [ ] **RULE-01**: 두 게임 모드는 136장, 각 TileID 4장, 일반 5를 대체하는 만·통·삭 적5 각 1장인 동일한 패산을 사용한다.
- [ ] **RULE-02**: 같은 시드는 같은 패산 순서를 만들고, 셔플은 마지막 원소를 포함한 모든 합법 위치를 선택할 수 있다.
- [ ] **RULE-03**: 패와 화료 결과의 `Equals`, `GetHashCode`, 비교 연산자는 동일한 정체성 규칙을 사용한다.
- [ ] **RULE-04**: 규칙 엔진은 일반형, 치또이츠, 국사무쌍을 포함해 가능한 모든 완전한 화료 분해를 찾는다.
- [ ] **RULE-05**: 여러 합법 분해가 있으면 실제 최종 지불액이 가장 높은 해석을 선택한다.
- [ ] **RULE-06**: 플레이어는 최소 한 개의 역이 있는 손으로만 화료할 수 있고 도라만 있는 손으로는 화료할 수 없다.
- [ ] **RULE-07**: 규칙 엔진은 멘젠·후로 여부와 화료 상황에 따라 역, 판, 도라, 역만 배수를 정확히 계산한다.
- [ ] **RULE-08**: 규칙 엔진은 머리·몸통·대기·멘젠 론·쯔모 조건에 따라 부를 계산하고 규칙에 맞게 올림한다.
- [ ] **RULE-09**: 정산 결과는 친·자의 론과 쯔모 지불자를 구분하고 각 지불액을 100점 단위로 올림한다.
- [ ] **RULE-10**: 동일한 패와 화료 맥락은 솔로와 4인 모드에서 동일한 화료 형태·역·판·부·기본 지불 결과를 만든다.

### Timed Solo Mode

- [ ] **SOLO-01**: 플레이어는 기존 180초 조패 모드를 별도 게임 모드로 시작할 수 있다.
- [ ] **SOLO-02**: 솔로 모드는 시작, 13장 배패, 쯔모, 타패, 화료 또는 패산 소진 후 새 손, 시간 종료 흐름을 유지한다.
- [ ] **SOLO-03**: 솔로 화료 점수는 기존 부스트·이동 거리·최종 거리·고득점 흐름에 한 번만 반영된다.
- [ ] **SOLO-04**: 플레이어는 시간 종료 또는 포기 후 결과를 확인하고 같은 씬에서 깨끗한 상태로 다시 시작할 수 있다.
- [ ] **SOLO-05**: 플레이어는 14장 손패에서 버리면 텐파이가 되는 패만 리치 타패 후보로 확인할 수 있다.
- [ ] **SOLO-06**: 플레이어가 유효한 리치 타패를 확정하면 1,000점이 공탁되고 손패가 고정된다.
- [ ] **SOLO-07**: 리치 후 플레이어는 합법 암깡·화료 외에는 방금 쯔모한 패만 버릴 수 있다.
- [ ] **SOLO-08**: 솔로 화료 결과에는 성립 조건에 맞는 리치, 일발, 우라도라가 반영된다.
- [ ] **SOLO-09**: 솔로 유국 시 리치봉은 다음 손으로 이월되고, 시간 종료 시 남은 리치봉은 거리 보상에 더해지지 않는다.

### Four-Seat Hanchan State

- [ ] **TABL-01**: 4인 모드는 사람 1명과 쯔모기리 더미 3명의 손패, 하천, 좌석풍, 점수와 턴 주인을 독립적으로 보유한다.
- [ ] **TABL-02**: 네 좌석은 각각 25,000점으로 시작하고 사람은 최초 동가로 시작한다.
- [ ] **TABL-03**: 한 국은 라이브 월, 14장 왕패, 도라 표시패와 네 좌석의 실제 배패를 사용한다.
- [ ] **TABL-04**: 게임 상태는 현재 행동 주체와 쯔모·타패·반응·정산·종료 단계를 명시적으로 구분한다.
- [ ] **TABL-05**: 잘못된 좌석, 지난 반응 창, 중복 입력 또는 종료된 국에 대한 행동은 상태를 변경하지 않고 거절된다.

### Tsumogiri Dummies

- [ ] **DUMY-01**: 각 더미는 자신의 차례에 라이브 월에서 패를 한 장 뽑고 바로 그 패를 버린다.
- [ ] **DUMY-02**: 더미의 기존 13장 손패는 쯔모기리로 변경되지 않는다.
- [ ] **DUMY-03**: 더미는 리치, 쯔모, 론, 치, 퐁, 대명깡, 암깡 또는 가깡을 선언하지 않는다.
- [ ] **DUMY-04**: 더미는 완성패여도 계속 쯔모기리하지만 유국 시 실제 손패의 텐파이·노텐 판정에는 참여한다.
- [ ] **DUMY-05**: UI와 포트폴리오 문서는 상대 좌석을 전략 AI가 아닌 `Tsumogiri Dummy`로 표시한다.

### Human Turn, Win, and Riichi

- [ ] **HUMN-01**: 사람은 자신의 턴에 패를 뽑고 쯔모 화료 또는 합법 타패를 선택할 수 있다.
- [ ] **HUMN-02**: 각 더미 타패 뒤 다음 쯔모 전에 사람에게 한 번의 론 또는 패스 반응 기회가 열린다.
- [ ] **HUMN-03**: 유효한 화료 형태, 최소 1역과 후리텐 조건을 모두 만족할 때만 론을 선택할 수 있다.
- [ ] **HUMN-04**: 자기 하천의 대기패가 있으면 사람은 모든 론을 할 수 없지만 쯔모 화료는 할 수 있다.
- [ ] **HUMN-05**: 화료 가능한 타패에 패스하면 다음 자신의 쯔모 또는 후로까지 일시 후리텐이 유지된다.
- [ ] **HUMN-06**: 리치 후 화료 가능한 타패에 패스하면 해당 국이 끝날 때까지 론할 수 없다.
- [ ] **HUMN-07**: 4인 모드의 리치는 합법 타패, 1,000점 공탁, 손패 고정, 일발, 우라도라와 리치봉 회수를 처리한다.

### Settlement and Match Progression

- [ ] **MTCH-01**: 사람의 론에서는 방총 더미가 기본 지불액과 본장을 전액 지불한다.
- [ ] **MTCH-02**: 사람의 쯔모에서는 세 더미가 친·자 지분과 본장을 각각 지불한다.
- [ ] **MTCH-03**: 한 번의 정산 결과가 모든 좌석 점수, 본장과 리치봉을 원자적으로 갱신하고 총점 보존을 검증한다.
- [ ] **MTCH-04**: 패산 소진 유국 시 네 좌석의 텐파이·노텐을 판정하고 총 3,000점 노텐벌부를 0/1/2/3/4명 텐파이 규칙에 맞게 정산한다.
- [ ] **MTCH-05**: 친 화료 또는 친 텐파이 유국이면 같은 국을 연장하고 본장을 하나 증가시킨다.
- [ ] **MTCH-06**: 비친 화료 또는 친 노텐 유국이면 친과 국을 진행하고, 비친 화료 시 본장을 0으로 초기화한다.
- [ ] **MTCH-07**: 리치봉은 다음 사람 화료자가 전부 회수하고 유국이면 다음 국으로 이월된다.
- [ ] **MTCH-08**: 대국은 동1국부터 남4국까지 진행하고 남4국도 동일한 친 연장 조건을 적용한다.
- [ ] **MTCH-09**: 남4국에서 친이 넘어가면 서입·토비·오라스 종료 선택 없이 반장전을 종료한다.
- [ ] **MTCH-10**: 반장 종료 시 미회수 리치봉은 어떤 좌석에도 지급하지 않고 결과 화면에 별도로 표시한다.

### Hanchan Presentation

- [ ] **HUI-01**: 플레이어는 메뉴에서 솔로 모드와 4인 반장전 모드를 구분해 시작할 수 있다.
- [ ] **HUI-02**: 4인 HUD는 장풍·국·본장·리치봉·남은 라이브 월·도라 표시패를 보여준다.
- [ ] **HUI-03**: 4인 HUD는 네 좌석의 점수·좌석풍·하천과 현재 턴을 보여준다.
- [ ] **HUI-04**: 결과 화면은 화료자, 방총자, 역·판·부, 지불자별 금액, 본장과 리치봉 변화를 보여준다.
- [ ] **HUI-05**: 플레이어는 솔로와 4인 모드를 각각 종료하고 같은 실행 세션에서 다시 시작할 수 있다.

### Human Calls and All Kans

- [ ] **CALL-01**: 더미 타패 후 사람에게 론을 최우선으로 한 합법 치·퐁·대명깡 조합과 패스만 제시된다.
- [ ] **CALL-02**: 사람은 바로 왼쪽 더미의 직전 타패로만 합법 치 조합을 만들 수 있다.
- [ ] **CALL-03**: 사람은 어느 더미의 직전 타패든 같은 패 두 장으로 퐁할 수 있다.
- [ ] **CALL-04**: 치 또는 퐁 후 사람은 정상 쯔모 없이 한 장을 버리고 호출자 다음 좌석부터 턴을 진행한다.
- [ ] **CALL-05**: 후로 직후 사람은 같은 패 또는 치한 순자의 반대편 패를 쿠이카에로 버릴 수 없다.
- [ ] **CALL-06**: 사람은 더미의 직전 타패와 같은 패 세 장으로 대명깡을 성립시킬 수 있다.
- [ ] **CALL-07**: 사람은 자신의 턴에 같은 은폐패 네 장으로 암깡을 성립시킬 수 있다.
- [ ] **CALL-08**: 사람은 자신의 턴에 기존 공개 퐁에 네 번째 패를 더해 가깡을 성립시킬 수 있다.
- [ ] **CALL-09**: 모든 성립한 깡은 왕패에서 영상패를 한 장 제공하고 타패 전에 새 깡도라 표시패를 활성화한다.
- [ ] **CALL-10**: 깡마다 라이브 월 마지막 패 하나가 왕패로 이동해 왕패는 항상 14장을 유지한다.
- [ ] **CALL-11**: 한 국에서 최대 네 번만 깡할 수 있고 마지막 라이브 월 쯔모 뒤에는 깡할 수 없다.
- [ ] **CALL-12**: 공개 멘츠를 포함한 손은 남은 은폐패와 함께 가능한 모든 4멘츠 1머리 화료 형태를 평가한다.
- [ ] **CALL-13**: 열린 손은 멘젠 전용 역을 받지 않고 열린 탕야오와 쿠이사가리 규칙을 적용한다.
- [ ] **CALL-14**: 열린·암 커쯔와 깡은 중장패·요구패 및 론·쯔모 상황에 맞는 부를 받는다.
- [ ] **CALL-15**: 영상패 화료에는 영상개화와 쯔모 정산을 적용하고 해저와 중복하지 않는다.
- [ ] **CALL-16**: 리치 화료에서는 활성 깡도라에 대응하는 깡우라도라까지 공개한다.
- [ ] **CALL-17**: 어떤 후로나 깡도 진행 중인 일발을 종료하고, 열린 손에는 이후 리치를 허용하지 않는다.
- [ ] **CALL-18**: 리치 후에는 일반 후로와 가깡을 금지하고, 손 구조와 대기가 유지되는 합법 암깡만 허용한다.

## Definition of Done

- 모든 v1 요구사항이 해당 로드맵 단계의 자동 또는 수동 검증을 통과한다.
- 관련 EditMode 및 PlayMode 테스트가 최종 제출 커밋에서 통과한다.
- Windows x64 Player 빌드가 성공하고 빌드된 실행 파일로 대표 시나리오를 확인한다.
- 기존 솔로 모드가 최종 구조에서도 종료·포기·재시작을 포함해 동작한다.
- 포트폴리오 문서와 영상의 주장은 최종 태그에서 실제로 재현 가능하다.
- Stage 3는 `PORT-07`을 만족할 때만 완료 및 공개된 것으로 간주한다.

## v2 Requirements

### Strategic Opponents

- **AIPL-01**: 상대 좌석은 합법 행동 목록에서 타패를 전략적으로 선택할 수 있다.
- **AIPL-02**: 상대 좌석은 자신의 상태와 테이블 상황에 따라 리치·쯔모·론을 선언할 수 있다.
- **AIPL-03**: 상대 좌석은 치·퐁·깡과 패스를 전략적으로 선택할 수 있다.
- **AIPL-04**: 향후 Mortal 등 외부 모델은 동일한 합법 행동 입력·선택 결과 경계를 통해 연결된다.

### Rule Extensions

- **RULEX-01**: 대국은 서입·토비·오라스 종료 선택을 규칙으로 지원할 수 있다.
- **RULEX-02**: 대국은 사풍연타·구종구패·사개리치·사깡산료 등 도중유국 결과를 지원할 수 있다.
- **RULEX-03**: 대국은 다중 론, 책임지불, 유국만관과 추가 규칙 변형을 지원할 수 있다.

## Out of Scope

| Feature | Reason |
|---------|--------|
| 네 명의 로컬 인간 플레이 | 숨김 정보와 입력 소유권 UI가 9일 핵심 범위를 벗어난다. |
| 네트워크 멀티플레이 | 동기화·재접속·권한·부정행위 방지가 별도 프로젝트 규모다. |
| 전략 AI 또는 Mortal 연동 | 단계 4로 연기하며 현재 더미를 AI로 과장하지 않는다. |
| 더미의 화료·리치·후로 | 상대 판단과 다중 반응 규칙을 요구하므로 단계 4 이전에는 금지한다. |
| 규칙 설정 화면과 여러 프리셋 | 고정 규칙 하나의 정확성과 테스트를 우선한다. |
| 도중유국·서입·토비·오카·우마 | 합의된 고정 기본 반장전 범위에 포함되지 않는다. |
| 데이터베이스·서버·온라인 순위표 | 현재 결과는 로컬 포트폴리오이며 클라이언트 점수를 신뢰하지 않는다. |
| 전면 UI·아트 리메이크 | 규칙 정확성, 두 모드 시연과 빌드 검증에 필요한 UI만 개선한다. |
| 전체 AI 대화 로그 공개 | 대표 판단 사례만 정리해 신호 대비 노이즈를 줄인다. |
